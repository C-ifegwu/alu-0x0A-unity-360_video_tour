# 360 Video Tour

An interactive virtual reality 360 video tour of the Holberton / ALU campus created with Unity.

## Features
- **360 Video Spheres**: Immersive 360 video environments for LivingRoom, Cantina, Cube, and Mezzanine.
- **Dynamic Hotspot Navigation**: Interactive UI hotspots connecting rooms with smooth fade-to-black camera transitions.
- **Interactive Info Boxes**: Floating World Space UI buttons that toggle detailed informational popup panels on click.
- **Background Music (BGM)**: Non-diegetic ambient soundtrack routing through Unity's `BGMMixer` on the dedicated `Music` audio group (-10.00 dB attenuation) that persists across room transitions.
